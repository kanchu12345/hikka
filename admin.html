Backend & Authentication Configuration Guide

How to secure this admin dashboard with genuine server-side authentication

Why Frontend Passwords are Not Secure:

Because GitHub Pages is a static host, any JavaScript code or passwords stored in the repository can be viewed by anyone inspecting the source code. True security requires server-side verification using an authentication provider.

Recommended Solutions:
  • Firebase Authentication (Pre-wired): Enable Email/Password or Google Auth in the Firebase Console. The Firebase client in js/firebase-client.js is already configured to sync data securely to Firestore.
  • Supabase Auth: Connect Supabase with Row Level Security (RLS) policies.
  • Cloudflare Access / GitHub OAuth: Protect the /admin.html route with an enterprise proxy gate.

Firebase Firestore Cloud Sync:

You can push your local browser edits to Firestore so that every visitor across the world sees your updates in real time.
